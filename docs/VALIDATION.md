# 구현 및 검증 상태

- 240개 퍼즐: 유일해, 연결된 영역, 정답 배치, 중복 없음 검사 통과.
- 엔진: 행/열/색 구역/대각선 충돌, 완료 조건 검사 통과.
- DOM 환경(jsdom): 튜토리얼, 탭 배치, 되돌리기, 클리어, 보상, 다음 레벨, 힌트 차감, 저장 후 재시작, 브라우저 가짜 광고 보상 없음, 패턴 설정, 드래그 상태, 날짜 고정 저장 검사 통과.
- 실제 브라우저 시각 검증 미완료: 현재 실행 환경에서 Chromium 프로세스가 socket 권한 오류로 종료됨. 별도 브라우저의 localhost는 인증 프록시를 반환함.
- Android APK 빌드 미완료: Gradle은 실행되었으나 Google Maven의 Android Gradle Plugin 8.9.2를 다운로드/해결하지 못함. 이 환경에 Android SDK도 없음. Java 컴파일 및 Android lint 통과를 주장하지 않음.
- GitHub Actions 빌드 워크플로 준비됨. 공개 main 업로드는 자동 승인 검토에서 거절되어 원격 저장소에는 아직 반영되지 않음.
- 실제 기기 광고 콜백, 시스템 뒤로가기, 엣지 투 엣지 레이아웃, 광고 동의 및 네트워크 오류 복구는 Android 빌드 후 검증 필요.
- Release에는 실제 AdMob ID와 개인 업로드 키, 공개 개인정보처리방침 및 Play Console 설정이 필요함.
